# Об использовании названий и материалов

APIStend не связан с ООО «1С-Битрикс», ООО «Интернет Решения» (Ozon) и
ООО «Вайлдберриз». Названия сервисов используются исключительно для указания
совместимости: APIStend воспроизводит формат их публичных REST API.

## Источники документации

| Сервис | Источник | Лицензия |
| --- | --- | --- |
| Bitrix24 | [github.com/bitrix24/b24restdocs](https://github.com/bitrix24/b24restdocs) | MIT, Copyright (c) 2024 Bitrix24 |
| Bitrix24, русские тексты | [apidocs.bitrix24.ru](https://apidocs.bitrix24.ru/) | не объявлена |
| Ozon Seller API | зеркало OpenAPI, снимок зафиксирован в `specs/ozon/SOURCE.json` | не объявлена |
| Wildberries | зеркало OpenAPI, снимок зафиксирован в `specs/wildberries/SOURCE.json` | не объявлена |

Точные даты снимков и sha256 — в файлах `specs/*/SOURCE.json`. Интерфейс API —
имена методов, параметры, коды ответов — авторским правом не охраняется
(ГК РФ ст. 1259 п. 5), поэтому каталог методов воспроизводится дословно.
Описания методов взяты из документации сервисов с сохранением ссылки на источник
у каждой записи каталога (поле `sourceUrl`).

Лицензия MIT в `LICENSE` распространяется на код APIStend, но не на материалы
документации сторонних сервисов.
