# Тексты интерфейса (RU)

Язык интерфейса — русский. Названия методов, пути, заголовки HTTP, JSON и команды CLI —
всегда латиницей и моноширинным шрифтом, не переводятся.

## Правила языка

- Обращение на «вы», без восклицаний и канцелярита.
- Кнопки — глагол в инфинитиве: «Создать ключ», «Отправить», «Сбросить сейчас».
- Заголовки панелей — существительное: «Настроенные вебхуки», «Журнал доставок».
- Надзаголовки блоков — ВЕРХНИЙ РЕГИСТР: «ТЕЛО ОТВЕТА · JSON», «ПЛЕЙСХОЛДЕРЫ».
- Разделитель в мета-строках — « · » (пробел, средняя точка, пробел).
- Числа: неразрывный пробел разрядов («128 940»), десятичная запятая («1,8 %»),
  единицы через пробел («84 мс», «4,2 КБ»).
- Время — `ЧЧ:ММ:СС` моноширинным; относительное время рядом: «2 мин назад».

## Пустые состояния

| Ситуация | Заголовок | Пояснение |
| --- | --- | --- |
| Поиск без результатов | Ничего не найдено | Попробуйте другой запрос или снимите фильтры |
| Нет методов в группе | Методы появятся позже | Раздел в работе — следите за дорожной картой |
| Нет своих моков | Пока нет своих моков | Создайте первый мок или импортируйте OpenAPI-файл |
| Нет логов за период | Запросов за период не было | Измените период или отправьте тестовый запрос |
| Агент не подключён | Локальная доставка не подключена | Запустите `apistend listen` в терминале проекта |

## Ошибки

| Код | Текст в интерфейсе |
| --- | --- |
| 401 | Неверный или отозванный ключ |
| 404 | Метод не найден в этой песочнице |
| 429 | Превышен лимит боевого API (эмуляция) |
| 500 | Ошибка сервиса — так отвечает боевой API в этом сценарии |
| timeout | Ответ дольше 30 секунд |
| сеть | Не удалось выполнить запрос. Повторить? |

Важно: 429 и подобные — **эмуляция ограничений боевого API**. Собственных лимитов у APIStend нет,
формулировки вроде «вы исчерпали квоту» недопустимы.

## Домены и идентификаторы, используемые в примерах

- API песочницы: `https://api.apistend.ru/{service}/…`
- Моки сервисов: `https://b24.mock.apistend.dev/rest/`, `https://ozon.mock.apistend.dev/v1/`,
  `https://wb.mock.apistend.dev/api/v3/`
- CLI: `apistend listen --forward localhost:3000/webhooks`, агент `apistend-cli 1.4.2`
- Ключи: префикс `stend_` (`stend_sbx_…` — песочница, `stend_sk_…` — серверный)
- Заголовок авторизации: `X-Mock-Key`
