# Экран «Каталог API»

`assets/screens/02-api-catalog.png` · справочник всех доступных методов демо-API.
Задача экрана: найти метод и понять, что он умеет, до того как звать его из кода.

Контент: паддинг 24, зазор 20.

## 1. Панель фильтров (высота 33)

Слева:
- Сегмент-контрол сервисов: «Все сервисы» (активен) · Bitrix24 · Ozon Seller · Wildberries.
- Фильтр «Метод:» — выпадающий список HTTP-методов.
- Фильтр «Готовность» — состояние мока (готов / обновляется / в планах).

Справа: `Search Field` 280 px, плейсхолдер по методам и описаниям.

## 2. Список методов — 752 px (тянется), высота 863

- **Шапка списка** (56): заголовок с количеством найденного, справа переключатель вида и сортировка.
- **Шапка колонок** (26): Метод · Эндпоинт · Описание · Версия · Готовность — 11 px / 600 `text-tertiary`.
- **Группы по сервисам**: строка-заголовок группы 31 px (название сервиса + точка цвета сервиса
  + счётчик методов), под ней строки методов.
- **Строка метода** (43 px, разделитель 1 px `border`):
  Method Badge · путь mono 12–13 px `text-primary` · описание 13 px `text-secondary` (тянется) ·
  версия mono 11 px `text-tertiary` · чип готовности.
- Состав в макете: Bitrix24 — `crm.deal.list`, `crm.deal.add`, `crm.contact.list`, `tasks.task.add`;
  Ozon — `/v3/product/info/list`, `/v3/posting/fbs/list`, `/v1/review/list`;
  Wildberries — `/api/v3/stocks/{warehouseId}` (GET и PUT), `/api/v3/supplies`, `/public/api/v1/prices`.
- **Пустая группа** («Wildberries Аналитика», 76 px) — образец пустого состояния:
  заголовок «Методы появятся позже» + пояснение, без иллюстрации. Используйте его как эталон
  для всех пустых состояний в продукте.
- **Футер списка** (44): счётчик показанных методов слева, пагинация/«показать ещё» справа.

## 3. Панель деталей метода — 372 px

- **Шапка** (135): Method Badge + путь mono 14 px, название метода 15 px / 600,
  чип готовности, кнопка «Открыть в консоли».
- **Тело** (596), разделы:
  - **Описание** — что делает метод, 13 px `text-secondary`, межстрочный 1.5.
  - **Параметры** — список: имя mono 12 px `text-primary`, тип 11 px `text-tertiary`,
    признак обязательности, короткое пояснение.
  - **Сценарии** — какие ответы умеет отдавать мок: `200 OK`, `401 Неверный токен`,
    `429 Лимит 60 запросов в минуту` (это эмуляция ограничений боевого API, а не лимит APIStend), `500`.
  - **Задержка** — типичное время ответа мока и диапазон настройки.
- **Футер** (64): базовый адрес мока mono 12 px + иконка `copy`, ссылка «Полная документация →».

**Поведение [правило]:** выбор строки в списке обновляет правую панель без перезагрузки;
адрес страницы содержит идентификатор метода (`/catalog/bitrix24/crm.deal.list`), чтобы им можно было делиться.
