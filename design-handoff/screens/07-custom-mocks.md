# Экран «Свои моки»

`assets/screens/07-custom-mocks.png` · пользователь создаёт собственные эндпоинты и описывает,
что они возвращают. Второй по важности экран продукта после «Обзора».

Контент: паддинг 24, зазор 20. Основное действие в шапке — «Новый мок».

## 1. Тулбар (34)

Сегмент-фильтры со счётчиками: «Все · 8» (активен) · «Активные · 5» · «Черновики · 2» · «Выключенные · 1».
Справа: `Search Field` «Поиск по своим мокам», `Button Secondary` «Импорт из OpenAPI», `Button Secondary` «Шаблоны».

## 2. Панель «Мои моки» — 420 px, высота 858

- Шапка: заголовок + счётчик в чипе, справа «по изменению» + иконка `arrow-up-down`.
- Строка мока (паддинг `12px 16px`, зазор 5, разделитель 1 px):
  - строка 1: Method Badge + путь mono 12 px (тянется) + точка состояния 7 px
    (success — активен, warning — черновик, `border-strong` — выключен);
  - строка 2: название 12 px / 500 `text-primary`;
  - строка 3: мета 11 px `text-tertiary` — «4 правила · 1 284 вызова · 2 мин назад».
  - Выбранная строка — фон `accent-soft`.
- Восемь записей: `/custom/erp/orders`, `/custom/erp/orders/{id}`, `/custom/catalog/products`,
  `/custom/catalog/products/{sku}`, `/custom/billing/invoices`, `/custom/logistics/shipments`,
  `/custom/crm/leads`, `DELETE /custom/erp/orders/{id}`.
- Футер: «+ Создать мок» (`accent`) и «Импортировать JSON» (`text-secondary`).

## 3. Редактор мока — 704 px (тянется)

**Шапка (высота ~60)**
Селектор метода (`POST` на `accent-soft` + `chevron-down`), путь mono 14 px / 500 (тянется),
Status Chip «Активен», `Button Secondary` «Тест-вызов», `Button Primary` «Сохранить».

**Вкладки**
Ответ (активна) · Правила ответа · Заголовки · Задержка и ошибки · История вызовов.

**Тело — две колонки**

*Слева (тянется, паддинг 16, зазор 10):*
- Надзаголовок «ТЕЛО ОТВЕТА · JSON» + ссылка «Форматировать» с иконкой `braces`.
- Редактор кода (тянется): фон `code-bg`, номера строк (колонка 16 px, `code-muted`),
  подсветка `code-key` / `code-string` / `code-number`, **плейсхолдеры `{{…}}` — цвет `code-template` `#C79BF2`**.
- Надзаголовок «ПРЕДПРОСМОТР · ШАБЛОНЫ ПОДСТАВЛЕНЫ» + чип `201 Created`.
- Блок предпросмотра: фон `surface-2`, mono 11 px `text-secondary` — тот же ответ с подставленными значениями.

*Справа (264 px, левая граница 1 px `border`, паддинг 16, зазор 18):*
- «КОД ОТВЕТА» — сегмент 200 / 201 / 400 / 500 (активен 201, цвет `accent`).
- «CONTENT-TYPE» — селект `application/json`.
- «ЗАДЕРЖКА ОТВЕТА» — значение `250 мс` + слайдер, диапазон 0–3000 мс.
- «Шаблонизация ответа» — тумблер (вкл) + пояснение 11 px `text-tertiary`.
- «ПЛЕЙСХОЛДЕРЫ» (над списком верхняя граница): чип с кодом и описание под ним —
  `{{uuid}}`, `{{now}}`, `{{now +3d}}`, `{{randomInt a b}}`, `{{faker.company}}`, `{{request.body.*}}`.

**Футер (высота ~50, фон `surface-2`)**
«Вызов:» + `POST` + `https://api.apistend.ru/custom/erp/orders` mono 12 px + иконка `copy`,
справа ссылка «Открыть в консоли →».

**Поведение [правило]:** несохранённые изменения — точка `warning` рядом с названием мока и
блокировка ухода со страницы; «Тест-вызов» выполняет запрос и показывает результат в блоке предпросмотра;
клик по чипу плейсхолдера вставляет его в позицию курсора в редакторе.
