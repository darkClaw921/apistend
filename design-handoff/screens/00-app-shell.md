# Каркас приложения (App Shell)

Общий для всех семи экранов приложения. Исходник в макете — фрейм `Screen Template`.

```
┌───────────┬──────────────────────────────────────────────────────┐
│           │  Topbar 64                                           │
│ Sidebar   ├──────────────────────────────────────────────────────┤
│ 248       │  Content  (padding 24, gap 16–20)                    │
│           │                                                      │
└───────────┴──────────────────────────────────────────────────────┘
   1440 × 1024
```

## Сайдбар — 248 px, фон `nav-bg`, высота 100 %

Вертикально: верхний блок и нижний блок прижаты к краям (`justify-content: space-between`).

**Верхний блок** (паддинг `16px 12px`, зазор 8):

1. **Логотип** — квадрат 30 × 30, радиус 8, фон `accent`, иконка `plug-zap` 17 px белая;
   рядом «APIStend» 15 px / 700 белый и подпись «демо-API для интеграций» 10 px `nav-text`.
2. **Переключатель песочницы** — блок `nav-bg-2`, граница `#26303C`, радиус 6, паддинг `9px 10px`:
   зелёная точка 7 px, надпись «Песочница» 10 px `nav-text`, значение `sandbox-01` mono 12 px белым,
   иконка `chevrons-up-down` 14 px справа.
3. **Разделы меню** — заголовок раздела (10 px / 600, трекинг 0.8, `#5D6A7A`) и пункты:

| Раздел | Пункты (иконка lucide) |
| --- | --- |
| ОБЗОР | Обзор `layout-dashboard` · Каталог API `library-big` · Сервисы `boxes` |
| РАБОТА | Консоль запросов `terminal` · Логи запросов `scroll-text` · Вебхуки `webhook` · Сценарии `git-branch` · Свои моки `database` |
| ПРОЕКТ | Ключи и токены `key-round` · Команда `users` · Настройки `settings` |

Стили пункта — в `../02-components.md`, п. 15. Экраны «Сервисы», «Сценарии», «Команда», «Настройки»
в макете не нарисованы — пункты есть, страницы проектируются позже.

**Нижний блок** (паддинг `12px 12px 16px`):

- Блок использования: `nav-bg-2`, радиус 6, паддинг 12 — строка «Запросов за месяц» 11 px `nav-text`
  и значение mono 11 px / 600 белым, ниже подпись «Без лимитов на запросы» 11 px `#5D6A7A`.
  Прогресс-бара нет: лимитов у продукта нет.
- Профиль: аватар 28 × 28 радиус 14 фон `#2E3A48` с инициалами 11 px / 600, имя 12 px / 500 белым,
  «Бесплатный доступ» 10 px `nav-text`, иконка `ellipsis-vertical` 14 px справа.

## Шапка (Topbar) — высота 64, фон `surface`, нижняя граница 1 px `border`

- Слева: хлебные крошки 11 px `text-tertiary` («Проект «Интеграция 1С» / Обзор») и
  заголовок экрана 17 px / 700, трекинг −0.2.
- Справа (зазор 10): глобальный поиск (`Search Field`, 280 px, плейсхолдер «Поиск методов, сервисов, логов»),
  две Icon Button (`book-open`, `bell`), основное действие экрана (`Button Primary`).

Основное действие по экранам: Обзор — «Новая песочница», Свои моки — «Новый мок»,
Ключи — «Создать ключ», Вебхуки — «Новый вебхук».

## Область контента

- Паддинг 24, вертикальный зазор 16–20 px (см. спецификацию экрана).
- Высота фиксирована (960 px внутри 1024). Панели с таблицами прокручиваются внутри себя,
  вся страница не скроллится.
- Типовая раскладка: верхняя панель фильтров/тулбар + двухколоночная рабочая область
  (список слева, деталка справа).

**[правило]** До 1280 px правую панель-деталку сворачивать в шторку; до 1024 px сайдбар — в бургер-меню.
