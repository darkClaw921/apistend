# Чек-лист приёмки вёрстки

Проверяется при ширине окна 1440 px, масштаб 100 %, шрифты Inter и JetBrains Mono загружены.

## Токены и типографика
- [ ] Ни одного цвета вне `tokens/tokens.css` (проверьте поиском по `#` в стилях).
- [ ] Отступы кратны шкале 4 / 8 / 12 / 16 / 24 / 32 (исключения — только внутренние паддинги строк таблиц).
- [ ] Радиусы: 6 — элементы управления, 10 — панели, 14 — карточки лендинга, 20 — чипы.
- [ ] Пути, JSON, ключи, коды, время — моноширинным шрифтом; заголовки и подписи — Inter.
- [ ] Числа с неразрывными пробелами разрядов и десятичной запятой.

## Каркас
- [ ] Сайдбар 248 px, не сжимается, активный пункт подсвечен `accent`.
- [ ] Шапка 64 px с хлебными крошками, заголовком и одним основным действием справа.
- [ ] Страница целиком не скроллится: скроллятся тела панелей, шапки и футеры панелей закреплены.
- [ ] В блоке использования нет прогресс-бара и упоминаний лимитов.

## Компоненты
- [ ] Кнопки: одна `Button Primary` на экран; hover, active, disabled, focus-visible реализованы.
- [ ] Method Badge: GET зелёный, POST акцентный, PUT оранжевый, DELETE красный.
- [ ] Status Chip: насыщенный цвет — текст и точка, `*-soft` — фон.
- [ ] Таблицы: шапка `surface-2`, разделители 1 px, hover-строка, выбранная строка `accent-soft`,
      ошибочные строки подсвечены прозрачным `danger-soft` / `warning-soft`.
- [ ] Блоки кода: подсветка по токенам `code-*`, плейсхолдеры `{{…}}` — `code-template`, есть копирование.

## Состояния данных
- [ ] Для каждой таблицы и списка есть загрузка (скелетон), пусто и ошибка загрузки.
- [ ] Поиск: дебаунс, счётчик совпадений, подсветка совпавшего фрагмента, состояние «ничего не найдено».
- [ ] Формы: валидация, блокировка кнопки при отправке, сообщение об успехе.
- [ ] Опасные действия (отзыв ключа, удаление мока) требуют подтверждения вводом названия.

## Экранные проверки
- [ ] Обзор: поиск ищет по всем трём сервисам, кнопка «Запрос» подставляет ответ в правую панель.
- [ ] Консоль: переключение сценария меняет ответ; Ctrl/Cmd + Enter отправляет запрос.
- [ ] Логи: фильтры комбинируются, выбранная строка раскрывается в правой панели, работает пагинация.
- [ ] Вебхуки: видно состояние локального агента; локальные адреса `localhost` выделены `accent`;
      «Отправить тестовое событие» добавляет запись в журнал доставок.
- [ ] Ключи: полный ключ показывается один раз при создании, дальше только маска; в колонке запросов нет квоты.
- [ ] Свои моки: плейсхолдеры вставляются кликом, предпросмотр показывает подставленные значения,
      несохранённые изменения не теряются при уходе.
- [ ] Лендинг: секции в порядке из спецификации, зачёркнутая цена, чип «Популярный», футер со ссылками.

## Доступность
- [ ] Контраст текста ≥ 4.5:1 (`text-tertiary` на `surface` — только для мета-текста от 11 px).
- [ ] Все действия доступны с клавиатуры, порядок табуляции логичен, фокус видим.
- [ ] Иконки-кнопки имеют `aria-label`; статус передаётся не только цветом (есть текст или иконка).
- [ ] Таблицы размечены семантически (`table`/`thead`/`tbody` или ARIA-grid).

## Сверка с макетом
- [ ] Каждый экран визуально совпадает с PNG из `assets/screens/` при 1440 px.
- [ ] Нет обрезанного текста и переполнений; длинные пути обрезаются многоточием, а не ломают строку.
